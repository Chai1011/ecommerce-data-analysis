# E-Commerce Data Analysis

## Project Overview
Analyzed an e-commerce dataset using Python and SQL to uncover business insights related to revenue trends, customer behavior, product performance, seller performance, returns, and delivery operations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- SQLAlchemy
- MySQL
- Matplotlib

## Project Workflow
1. Data Cleaning and Preprocessing using Python
2. Exporting Cleaned Data to CSV
3. Loading Data into MySQL using SQLAlchemy
4. SQL-based Business Analysis
5. Data Visualization and Insight Generation

## Dataset
The project consists of multiple tables:
- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Returns
- Delivery Logs

## Key Analysis
- Monthly Revenue Trends
- Month-over-Month Growth
- Top Revenue Generating Cities
- Average Order Value Analysis
- Customer Lifetime Revenue
- Return Analysis
- Delivery Performance Analysis
- Seller Performance Analysis

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- SQL Joins
- CTEs
- Sub Queries
- Clauses / Single and Multirow Functions
- Window Functions
- Aggregations
- Business Insight Generation
